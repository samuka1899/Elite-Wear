# EliteWear - Premium Clothing Store

Este é o projeto da **EliteWear**, uma loja de roupas moderna e premium focada em streetwear de alta qualidade.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Vanilla) com design responsivo
- JavaScript para interatividade
- Estética moderna com efeitos holográficos e animações fluidas

## ✨ Funcionalidades
- Navegação intuitiva entre categorias
- Design focado na experiência do usuário (UX)
- Páginas de Login e Cadastro personalizadas
- Seções de Destaques, Conjuntos e Novidades

## 🌐 Como visualizar
Para ver o projeto localmente, basta abrir o arquivo `index.html` em qualquer navegador.
